# AudioBook Studio

<p align="center">
    <img src="/public/screenshot.png">
</p>

A local Audiobook editor that uses local Ai to generate speech.

- 💬 Local In-Browser AI
- 🌀 WebGPU
- 🦖 100% Offline
- ⚫️ Dark & Light Theme


### Local Set-up
```sh
git clone git@github.com/anthonybudd/Audiobook-Studio.git
cd Audiobook-Studio

npm i
npm run dev

open http://localhost:3000
```
